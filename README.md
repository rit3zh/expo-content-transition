Native content transitions for React Native + Expo.

```bash
bun add expo-content-transition
```

```tsx
import { NumericText } from 'expo-content-transition';

<NumericText value={123.45} fontSize={48} />;
```

Read the docs at **[transition.rit3zh.dev](https://transition.rit3zh.dev)**.
