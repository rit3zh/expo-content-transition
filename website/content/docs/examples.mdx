Each example runs live, and the code beside it is the React Native component that produces it. Examples that play themselves stop as soon as you press or type inside them; the reset button starts them again.

A number you step up and down. Only the digits that change move.

## Clock

Wall-clock time, one tick a second. Midnight would read as a smaller number, so it always rolls up.

<Example id="clock" />

## Stock ticker

## Status label
